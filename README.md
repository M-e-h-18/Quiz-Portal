# ⚡ Quiz Portal ⚡

A dynamic, interactive web application for taking quizzes on a variety of topics, including programming, data tools, entertainment, sports, games, and more.

---

## 🚀 Update Notice

This branch (**update1**) is a major upgrade over the main branch. It transforms the project from a basic React template into a fully-featured quiz portal with:

- Timed/untimed quizzes  
- XP system & levels  
- Lifelines  
- Leaderboard  
- Animated UI  
- Dozens of quiz topics

---

## Features

- **Wide Variety of Quizzes:** Topics include Java, C++, Python, DBMS, Power BI, Tableau, Sports, Music, Cooking, Riddles, Cards, and more.  
- **Multiple Choice Questions:** Each quiz contains multiple carefully crafted questions with 4 answer choices.  
- **Timed and Untimed Modes:** Users can choose to take quizzes with a timer for added challenge or without for a more relaxed experience.  
- **XP and Level System:** Earn XP for correct answers and speed bonuses; level up as you score higher.  
- **Lifelines:** Use up to 3 lifelines per quiz to eliminate two wrong options, increasing your chances.  
- **Leaderboard:** After completing a quiz, your score and XP are recorded; compare your performance with others.  
- **Animated UI:** Uses motion effects for a visually engaging experience.

---

## Technology Stack

- **Frontend:** React.js, HTML, CSS, JavaScript  
- **State Management:** React Hooks (`useState`, `useEffect`)  
- **Animation:** Framer Motion for smooth transitions  
- **Storage:** Local Storage for leaderboard and user progress
